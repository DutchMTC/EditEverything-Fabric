Edit Everything — Minecraft Fabric mod
=====================================

See README.md for the Modrinth project description, features, installation
instructions and commands.

The current branch targets Minecraft 26.3 and requires Java 25,
Fabric Loader 0.19.3 or newer, and Fabric API 0.161.0 or newer for 26.3.

Build from source:
    Windows:       .\gradlew.bat build --console=plain
    Linux/macOS:   ./gradlew build --console=plain

Artifacts are written to build/libs/. Install the mod JAR, not the sources JAR.
Launch the development client with the runClient Gradle task.
